# CodeAlpha - Sentiment Analysis

## Objective

To analyze customer reviews and classify them into Positive, Negative, or Neutral sentiments using Natural Language Processing (NLP).

## Tools Used

* Python
* Pandas
* TextBlob
* Matplotlib
* Google Colab

## Dataset

Amazon Reviews Dataset

## Analysis Performed

* Data Loading
* Text Processing
* Sentiment Classification
* Sentiment Distribution Visualization

## Key Insights

1. Positive reviews were more frequent than negative reviews.
2. Customer opinions can be automatically classified using NLP techniques.
3. Sentiment analysis helps understand customer satisfaction levels.
4. Visualizations provide a clear overview of sentiment distribution.

## Conclusion

The project successfully classified customer reviews into Positive, Negative, and Neutral categories and visualized the results using Python.
